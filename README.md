# Website Portal Informasi Desa

Website informasi dan pelayanan publik desa terintegrasi yang mencakup program pemberdayaan masyarakat, administrasi hukum, fasilitas infrastruktur, pertanian, UMKM, kesehatan, serta promosi potensi desa bilingual.

## Informasi Projek
- **Tech Stack:** Laravel 11, Filament PHP v3, Tailwind CSS
- **Tema Warna:** Biru Utama (`#1e40af`) & Kuning Aksen (`#facc15`)
- **Fitur Utama:** Panel Admin CRUD (Filament) dan Halaman Publik Informatif dengan Dropdown Navigasi.

## Struktur Konten Utama (8 Modul)
1. **Ilmu Pemerintahan:** Profil Pemerintah Desa, struktur organisasi, visi-misi.
2. **Hukum:** Panduan Layanan Administrasi Desa (Syarat KTP, KK, SKCK, dll).
3. **Teknik Sipil:** Peta Fasilitas Umum Desa (Embed Google Maps / Koordinat).
4. **Teknik Mesin:** Panduan Perawatan Alat Pertanian (Traktor, pompa air, dll).
5. **Akuntansi:** Template Pembukuan Sederhana UMKM/Kelompok Tani (Downloadable Excel).
6. **Akuntansi Perpajakan:** Panduan Alur Administrasi Pajak UMKM.
7. **Bahasa & Kebudayaan Jepang:** Profil Potensi Desa Bilingual (Indonesia - Jepang).
8. **Kesehatan Masyarakat:** Jadwal & Informasi Posyandu serta Kontak Bidan Desa.

## Persyaratan Sistem
- PHP >= 8.2
- Composer
- Node.js & NPM
- MySQL / MariaDB
